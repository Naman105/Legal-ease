#Legal Ease – Privacy-First AI Contract Analyzer

Legal Ease is an AI-powered contract analysis platform that simplifies complex legal agreements into clear, actionable insights while keeping user privacy at the core. Unlike traditional AI document analyzers, all Personally Identifiable Information (PII) is masked directly in the browser before any content is sent to the AI, ensuring sensitive information never leaves the user's device.

The application provides clause-by-clause legal analysis, risk assessment, simplified explanations, negotiation recommendations, multilingual support across 8 Indian languages, voice output, and professionally formatted PDF reports. Powered by Google's Gemini AI, it is designed to make legal documents understandable for students, freelancers, startups, and small businesses without requiring legal expertise.

✨ Key Features
🔒 Privacy-first architecture with client-side PII masking
🤖 AI-powered legal reasoning using Gemini
📄 Clause-by-clause contract analysis
⚠️ Risk categorization (Low, Medium, High)
📚 References to relevant Indian legal principles
💡 Plain-language explanations for non-lawyers
🌐 Support for 8 Indian languages
🔊 Text-to-speech for accessibility
📑 Professional multilingual PDF report generation
⚡ React + FastAPI architecture for a fast user experience

🛠 Tech Stack:
Frontend: React, JavaScript, CSS
Backend: FastAPI, Python
AI Model: Google Gemini
PDF Generation: ReportLab
Document Processing: PyPDF2 / PDF parsing
